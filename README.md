# Cadence

A native iOS app that plans a week of strength, running and hot yoga around training load and
the weather, generates each lifting session with a chosen focus area, and progresses every load
from reps in reserve.

Built with SwiftUI and Liquid Glass on iOS 26, SwiftData for storage, Swift Charts, HealthKit for
runs and yoga from Apple Fitness, and Open-Meteo for the forecast. The training maths lives in a
dependency-free Swift package with its own tests.

See `CLAUDE.md` for the layout, the build commands and the reasoning behind the training model.
